# Smart-Registration-FormStudent Details Task

A simple and responsive Student Details Management web application built using HTML, CSS, and JavaScript.

The application allows users to enter student information through a form and dynamically display the details in a table. Each student record can also be deleted using the Delete button.

Features

- Student registration form
- Input fields for:
  - Name
  - Age
  - Gender
  - Course
  - E-mail
- Form validation using HTML "required" attributes
- Dynamically adds student details to the table
- Delete individual student records
- Automatically resets the form after saving
- Clean and simple user interface
- No page refresh required

Technologies Used

- HTML5 – Structure of the application
- CSS3 – Styling and layout
- JavaScript – DOM manipulation and functionality

How It Works

1. Enter the student's details in the form.
2. Select the gender and course.
3. Click the Save button.
4. JavaScript collects the entered values.
5. A new row is dynamically created and added to the table.
6. Click Delete to remove a student record.
